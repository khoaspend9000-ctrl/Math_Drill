## RNG note (Phase 18)
`web/js/mt19937.js` exists but is **not** wired into the question generator.
Per the M32.2 differential, Desktop and Web produce the same *structure*
(4 options, answer present, same template family) but different random values
because Python seeds Mersenne Twister and the Web uses `Math.random`.
**No parity requirement for seed-for-seed equality has been identified in
Desktop source or tests.** Recorded as a WEB_PLATFORM_IMPLEMENTATION DIFFERENCE.
`Math.random` was **not** replaced.
