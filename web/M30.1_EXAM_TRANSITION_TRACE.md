## Exam gating result
- **Desktop source behaviour:** no milestone concept. The exam unlocks only when
  every lesson for the player's grade is unlocked (`main.py:690-691`); otherwise
  it reports how many remain for 3.0s (`main.py:696-698`).
- **Web behaviour before M30.1:** a fabricated `locked: 'M10'` flag.
- **Is `M10` source-correct?** **NO.** It was invented, exactly like the `M7`
  Time Attack lock that M29.2 removed. It is now replaced by the Desktop formula.
- **Exam remains gated for ordinary players** because the rule is genuinely
  strict (Grade 3 needs level 481 for all 81 lessons). That is correct, not a bug.
